# Catálogo CAURÉ BRAND 👟

Catálogo web oficial de tenis para **CAURÉ BRAND**, listo para desplegarse gratis en **GitHub Pages**.

- **82 modelos** de 10 marcas (New Balance, Adidas, Nike, Jordan, On, Puma, Reebok, Louis Vuitton, Vans, Alexander McQueen).
- Filtros dinámicos por **Marca**, **Tipo** (Urbano, Running, Trail, Skate, Básquet) y **Público** (Hombre, Mujer, Unisex).
- Buscador interactivo en tiempo real.
- Visualización de imágenes optimizada: **se respeta el tamaño y proporción de cada calzado sin cortes ni deformaciones**, con vista previa en pantalla completa (Lightbox).
- Botón directo de **pedidos por WhatsApp** (+57 300 883 1730) con mensaje precargado del modelo exacto.
- 100% responsivo para móviles y computadores, compatible con modo claro y oscuro.
- Archivo único autónomo (`index.html`), sin dependencias de backend ni servidores externos.

## 🚀 Pasos para subirlo y activarlo en GitHub Pages

### Paso 1: Crear el repositorio en GitHub
1. Inicia sesión en [GitHub](https://github.com).
2. Haz clic en el botón verde **"New"** (o en **"Create repository"**).
3. En **Repository name**, escribe el nombre que desees (por ejemplo: `catalogo-caure` o `caurebrand`).
4. Selecciona **Public**.
5. Haz clic en **Create repository**.

### Paso 2: Subir los archivos
1. En la página de tu repositorio recién creado, haz clic en el enlace **"uploading an existing file"** (o en **Add file > Upload files**).
2. Arrastra los archivos de esta carpeta:
   - `index.html` (imprescindible)
   - `.nojekyll`
   - `README.md`
3. Abajo, en el botón verde, haz clic en **Commit changes**.

### Paso 3: Activar GitHub Pages (Sitio Web Público)
1. En la pestaña superior de tu repositorio, haz clic en **Settings** (Configuración ⚙️).
2. En el menú lateral izquierdo, haz clic en **Pages**.
3. En la sección **Build and deployment**:
   - **Source**: selecciona `Deploy from a branch`.
   - **Branch**: selecciona `main` (o `master`) y la carpeta `/(root)`.
   - Haz clic en **Save** (Guardar).
4. Espera 1 minuto y recarga la página. Verás un mensaje en verde con tu enlace oficial:
   > **Your site is live at: `https://<tu-usuario>.github.io/<nombre-del-repo>/`**
